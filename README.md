# 4А.Консалтинг

Тестовое задание. Node.js + TypeScript.

## Требования

- Node.js 18+
- npm или pnpm

## Установка

```bash
npm install
```

## Скрипты

| Команда   | Описание                    |
|----------|-----------------------------|
| `npm run dev`   | Запуск в режиме разработки (с перезагрузкой) |
| `npm run build` | Сборка в `dist/`            |
| `npm start`     | Запуск собранного приложения |
| `npm run typecheck` | Проверка типов без сборки |

## Структура

```
├── src/
│   └── index.ts   # Точка входа
├── dist/          # Сборка (генерируется)
├── package.json
├── tsconfig.json
└── README.md
```
